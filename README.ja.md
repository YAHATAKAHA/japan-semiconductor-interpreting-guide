### 公開ステージAIの外側で求められる「専任の日英・日中技術通訳」

公開講演ステージでAI翻訳や会場音声が提供される場合でも、ブース裏の技術仕様協議、価格・納期交渉、半導体工場・クリーンルーム視察、経営層会食では、文脈・条件・機密を正確に扱う専任の人間通訳が必要です。

* **料金（税込）**：EMYSTIプロ通訳者 1時間 12,000円〜（半日4時間 48,000円〜 / 1日8時間 96,000円〜）、代表通訳 Christine Lee 1時間 13,500円〜（半日 54,000円〜 / 1日 108,000円〜）。

### TransHero アプリ：半導体対話の翻訳最適化＋1週間同時通訳トライアル枠

東京会期（12月9日〜11日）の来場者・出展チーム向けに、半導体会話文脈を最適化した **TransHero** アプリ（ https://transhero.jp/ja/ ）の**1週間同時通訳トライアル枠**も併用いただけます。ブースの一次受付やちょっとした確認はアプリで、重要な商談・工場視察はオンライン予約でプロ通訳へつなぐ二層運用が可能です。
